# spit-bash

`spit-bash`, the runner for [SPIT](https://github.com/eclnz/spit), is developed in SPIT's repository, under [`runner/`](https://github.com/eclnz/spit/tree/dev/runner). Its code, documentation and issues are there, and this repository is archived.

To install it, clone SPIT and, from the repository's root:

```sh
python3 -m pip install ./runner
```

The runner's history, up to the commit it was moved at, is kept in SPIT's repository as well, so `git log -- runner/` there follows each file back.
